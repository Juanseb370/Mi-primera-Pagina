# Mi Primera Página
Taller de nivelación web

## Solución Parte Teórica

**Fundamentos de HTML**
* **HTML:** Es el esqueleto de la página. Sirve para armar la estructura y organizar todo el contenido.
* **Etiquetas:** Son los comandos entre `< >` que definen qué es cada cosa. Las más usadas son `<div>`, `<p>`, `<h1>` y `<img>`.
* **Atributos:** Son datos extra para personalizar las etiquetas. Por ejemplo, `class` y `id` para darles estilo luego, o `href` para los enlaces.

**Estilos con CSS**
* **CSS:** Es lo que pone bonita la web. Si HTML es el esqueleto, CSS es la ropa y los colores.
* **Propiedades CSS:** Son los detalles visuales que cambias, como `color` (texto), `background` (fondo) o `margin` (espacios).
* **Selectores:** Es cómo le avisas a CSS a qué elemento ponerle el estilo. Puede ser por etiqueta (`p`), por clase (`.boton`) o por ID.

**Interactividad con JavaScript**
* **JavaScript (JS):** Es lo que le da vida a la web. Hace que sea interactiva, como cuando haces clic y sale un menú sin recargar la página.
* **Tipos de datos:** Los más básicos son textos (`String`), números (`Number`) y verdadero/falso (`Boolean`).
* **Estructuras de control:** Los `if/else` son para tomar decisiones (ej. "si pasa esto, haz aquello"), y los bucles `for`, `while` sirven para repetir tareas automáticamente.
* **Nombres claros:** Sirven para que tú o tu equipo entiendan el código después. Es mejor ponerle un nombre claro a una variable que una simple `x` que luego no sabes qué es.
* **Variables de entorno:** Son configuraciones guardadas fuera del código donde escondes contraseñas o claves importantes por pura seguridad.

**Herramientas de Desarrollo (DevTools)**
* **DevTools de Chrome:** Es un panel integrado para inspeccionar y arreglar páginas. Lo abres con F12 o dando clic derecho e "Inspeccionar".
* **Panel Elements:** Te muestra el HTML y CSS. Es genial para hacer cambios rápidos de diseño ahí mismo en vivo y ver cómo quedan.
* **Panel Console:** Es la pantalla donde el navegador te avisa de errores. También sirve para probar pedacitos de código JavaScript rápido.
* **Panel Network:** Te muestra todo lo que la web está descargando (fotos, datos). Es clave para saber si la página está lenta o si algo falló al cargar.
